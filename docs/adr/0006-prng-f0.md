# ADR 0006 — PRNG e fluxos por sistema em F0

Status: aceita para simulationVersion `0.1.0`.

## Contexto

SPEC-000 exige repetição determinística, estado RNG serializado e fluxos separados por sistema. Criar fluxos percorrendo um catálogo global em ordem ASCII faria a adição de um módulo poder deslocar os estados iniciais existentes.

## Decisão

- A seed lógica tem exatamente 16 caracteres hexadecimais minúsculos (64 bits sem sinal).
- IDs de sistema são ASCII, namespaced, estáveis e únicos, com no máximo 128 caracteres e formato `^[a-z][a-z0-9]*(?:[.:/_-][a-z0-9]+)*$`.
- O estado inicial de um fluxo é derivado do XOR entre o valor uint64 da seed e o FNV-1a 64 do ID ASCII. FNV-1a usa offset basis `0xcbf29ce484222325`, prime `0x00000100000001b3` e overflow módulo 2⁶⁴.
- O valor resultante inicializa SplitMix64. Cada chamada soma `0x9e3779b97f4a7c15` módulo 2⁶⁴, aplica os shifts/multiplicadores publicados e produz um word de 64 bits. Dois words consecutivos preenchem xoshiro128** 1.1 na ordem `[low32(word1), high32(word1), low32(word2), high32(word2)]`.
- O xoshiro state é `[s0,s1,s2,s3]` em quatro uint32; estado `[0,0,0,0]` é substituído por `[1,0,0,0]`. Uma chamada retorna `rotl(s1 × 5, 7) × 9` módulo 2³² e avança o estado pela transição 1.1 dos autores.
- Cada stream é criado sob demanda por ID. O save registra algoritmo, derivação, quatro words e cursor de draws. O cursor precisa ser inteiro seguro; excedê-lo causa diagnóstico, sem wraparound.
- A saída inteira é uint32. `nextRandomFloat` divide por 2³², produzindo um valor em `[0,1)`. Esta não é uma fonte criptográfica.

## Vetores de referência

Para xoshiro128** com estado `[1,2,3,4]`, os oito primeiros uint32 são:

`11520, 0, 5927040, 70819200, 2031721883, 1637235492, 1287239034, 3734860849`.

Para seed `0000000000000000` e ID `core:foundation`, FNV-1a 64 é `39bd8bf1cb08640d`; o estado derivado é `[372660700,1130640584,3951875994,232408429]`; os quatro primeiros draws são `1319343464,2472902213,1021153040,3668185080`.

Para SplitMix64 com estado inicial zero, os dois primeiros outputs são `e220a8397b1dcdaf` e `6e789e6aa1b965f4`.

## Consequências

Adicionar um novo ID não muda a derivação dos streams existentes. Alterar FNV, SplitMix, mapeamento dos words, xoshiro, fallback zero ou conversão para float requer novo identificador de derivação/algoritmo e migração versionada. Os vetores acima são fixtures obrigatórias.

Implementação de referência dos autores: [SplitMix64](https://prng.di.unimi.it/splitmix64.c) e [xoshiro128** 1.1](https://prng.di.unimi.it/xoshiro128starstar.c).
